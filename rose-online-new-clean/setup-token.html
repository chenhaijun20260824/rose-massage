☁️ 云端同步设置（多设备共享数据）
📌 这是什么？

开启后，你在一台手机/电脑上添加的按摩技师、审核记录，会自动同步到另一台设备，不用重复录入。数据存在你自己的 GitHub 私密仓库里，别人看不到。

第 1 步：去 GitHub 领一把「钥匙」（只需做一次）

这把「钥匙」叫 PAT（个人访问令牌），它让本应用能读写你的云端数据。点击下方按钮，会自动打开 GitHub 的创建页面。

① 页面打开后，给令牌起个名字（随便写，如「玫瑰按摩同步」）
② 找到权限区，勾选 gist（关键！不勾就无法同步）
③ 拉到最下面点 Generate token（生成令牌）
④ 生成后显示一长串字符（ghp_ 开头），立刻复制（只显示这一次！）

想手机和电脑看同一份数据：先在手机上创建（这里留空），成功后把下面显示的 Gist ID 抄到电脑上、填成一样即可。各填各的 = 各用各的数据。
