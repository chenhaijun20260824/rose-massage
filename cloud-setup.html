☁️ 云端配置

用 GitHub 仓库当云数据库 · 无大小截断
准备工作（一次性）：
1. 登录 GitHub → New repository → 名字如 rose-massage-data，Public，Initialize with README 打勾；
2. 进入仓库 → 顶部 Add file → Create new file → 路径填 data/accounts.json，内容 []，提交；
3. 同样创建 data/technicians.json / data/notices.json / data/audit_log.json，内容都是 []；
4. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens，建一个有 Contents: Read and write 权限（限定到 rose-massage-data 仓库）的 Token，复制。
老式 Token 也行，只要勾了 repo 权限即可。
