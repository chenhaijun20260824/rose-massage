📘 图文指引：创建 GitHub 令牌

只需做一次，之后手机和电脑就能共享同一份按摩数据

⚠️ 小提示：GitHub 账号免费注册（用邮箱即可）。如果还没有账号，先去 github.com 注册一个，再回到这里。
1

打开令牌创建页

在手机或电脑浏览器里，打开这个网址：
github.com/settings/tokens/new
（也可以：GitHub 右上角头像 → Settings → 左侧 Developer settings → Personal access tokens → Tokens (classic) → Generate new token）。

【截图位置】GitHub 令牌创建页面（Note / Expiration / Select scopes 区域）
2

给令牌起个名字

在 Note 那一栏，随便写一个名字，比如「玫瑰按摩同步」。方便以后认得它。

【截图位置】Note 输入框填写示例
3

勾选 gist 权限（最关键的一步）

往下找到权限列表，勾选 gist 这一项。只有勾了它，应用才能读写你的云端数据。其他项都不用勾。

【截图位置】Select scopes 里 gist 被勾选的样子
4

生成令牌

拉到页面最下面，点绿色按钮 Generate token（生成令牌）。

【截图位置】绿色的 Generate token 按钮
5

复制那串字符（只显示这一次！）

生成后会显示一长串字符，通常以 ghp_ 开头。立刻点「复制」按钮复制下来。
⚠️ 这串字符关掉页面后就再也看不到了，所以现在就复制好。

【截图位置】生成后的令牌字符串（已打码）
6

粘回应用，完成

回到应用的「云端同步设置」页面（setup-token.html），把复制的字符粘贴到「GitHub 令牌」框里，点「保存并测试连接」。显示 ✅ 就成功了！

【截图位置】应用里粘贴令牌并测试连接成功
💡 多设备共用：第一台设备（比如手机）填令牌后留空 Gist ID，会自动创建；成功后页面会显示一个 Gist ID，把它抄到第二台设备（比如电脑）的 Gist ID 框里，两台就共享同一份数据了。
